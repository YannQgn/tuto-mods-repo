Guide R.E.P.O. Steam

Installer des mods

Tu as un code. r2modman ou Thunderstore Mod Manager installent les mods. Les captures sont faites dans r2modman. Sur Thunderstore, les boutons sont les mêmes.

r2modman Choisir le jeu Importer le pack Lancer Thunderstore Un problème

Installer r2modman

  1. Télécharger r2modman 3.2.19 (zip). Ouvre le zip, lance r2modman Setup 3.2.19.exe, et suis l'installateur.

Choisir R.E.P.O.

Ouvre r2modman. Dans Game selection, cherche R.E.P.O. et clique dessus.

Importer le pack

Le code :

01a0c56c-7eef-af1f-c8cb-6c550fa70917

  1. Clique Import / Update.
  2. Import new profile.
  3. From code.
  4. Colle le code, puis Continue.
  5. Tu vois les mods du pack. Clique Import.
  6. Choisis un nom, puis Create.
  7. Attends la fin du téléchargement. Ne ferme pas r2modman.
  8. Clique le profil, puis Select profile.
  9. Start modded, en haut à gauche.

Si tu lances R.E.P.O. depuis Steam, tu joues sans mods. Start vanilla fait pareil.

Thunderstore Mod Manager

Même code, même clics. Le programme passe par Overwolf.

Télécharger Thunderstore Mod Manager. Le bouton Download on Overwolf installe aussi Overwolf.

Ouvre le programme, cherche R.E.P.O., puis suis les mêmes étapes que plus haut : Import / Update, Import new profile, From code, colle le code, Import, donne un nom, attends le téléchargement, Select profile.

Pour jouer, clique Modded, en haut à droite. Vanilla lance le jeu sans mods.
