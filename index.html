Coller le code

01a0c56c-7eef-af1f-c8cb-6c550fa70917
  1. Clique Import / Update.
  2. Import new profile.
  3. From code.
  4. Colle le code, puis Continue.
  5. Tu vois les mods du pack. Clique Import.
  6. Choisis un nom, puis Create.
  7. Attends la fin du téléchargement. Ne ferme pas le programme.
  8. Clique le profil, puis Select profile.
  9. Lance le jeu depuis le programme. Sur r2modman : Start modded, en haut à gauche. Sur Thunderstore : Modded, en haut à droite.
